적용한 화학 원리

같은 종류의 원자 두 개가 결합한다고 가정하면 공유결합 반지름 R의 합이 기본 결합 길이를 결정합니다. 결합 차수가 커질수록 결합 길이는 짧아지는 경향을 반영해 보정합니다.

r = 2R − c(n−1)　│　E(n,R) = E₁(n) · (r₁/r)β

단위: R, r, c는 pm, E는 kJ·mol⁻¹, n과 β는 무차원입니다. 여기서 E₁(n)은 기준 결합 차수별 실제 자료를 이용한 기준 에너지입니다.

모델의 가정과 한계

  • 두 원자의 공유결합 반지름이 같다고 가정하여 R1 = R2 = R로 단순화했습니다.
  • 결합 차수 1, 2, 3에서 결합 길이가 감소하는 경향을 선형 보정식으로 나타냈습니다.
  • 결합 에너지는 실제 대표 결합 자료를 기준으로 만든 경험적 관계이며, 모든 원소와 분자에 적용되는 물리 법칙은 아닙니다.
  • 분자의 혼성화, 전기음성도, 공명, 결합 환경, 분자 구조 등은 독립적으로 반영하지 않았습니다.
