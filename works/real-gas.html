탐구 내용 및 모델 설명

1. 탐구 질문
기체의 온도(T), 부피(V), 몰수(n) 및 반데르발스 상수(a, b)의 변화가 이상 기체 상태 방정식과 반데르발스 방정식으로 계산한 압력 차이(Delta P)에 어떠한 영향을 미치는가?

2. 화학 원리 및 수식 논리
- 이상 기체 상태 방정식: P_ideal = (n * R * T) / V (R = 0.0821 L*atm/mol*K)
- 반데르발스 상태 방정식: P_vdw = (n * R * T) / (V - n * b) - (a * n^2) / V^2
- 분자 간 인력 보정항 (a * n^2) / V^2은 측정 압력을 감소시키고, 자체 부피 보정항 n * b는 기체가 이동 가능한 실제 부피를 줄여 압력을 증가시킵니다.

3. 모델의 가정과 한계 및 예외 처리 로직 (직접 검토 내용)
- 가정: 반데르발스 상수 a와 b는 온도나 압력 조건이 변해도 항상 일정하다고 가정합니다.
- 한계 및 검토 수정: 부피(V)가 매우 작아질 때 인력 보정항 (a * n^2) / V^2이 폭발적으로 증가하여 계산 압력이 음수(< 0 atm)로 떨어지는 물리적 오류를 발견했습니다. 이는 실제 기체가 고압·소부피 조건에서 액체로 상전이(응축)되는 현상을 단일 반데르발스 방정식이 완벽히 표현하지 못하기 때문입니다.
- 코드 수정 반영: 부피가 자체 부피 n * b 이하로 감소하는 것을 방지하도록 최소 부피 제약(1.05 * n * b)을 적용하였고, 계산 결과가 0 이하가 되는 구간은 '액화(응축) 발생 영역'으로 판정하여 압력을 0.000 atm으로 보정 처리하였습니다.
