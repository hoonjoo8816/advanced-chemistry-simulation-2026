# 2026 고급화학 시뮬레이션 수행평가

3학년 고급화학 시뮬레이션 수행평가의 안내, 주제 신청, 제작 자료, 최종 제출과 학생 작품 공유를 한곳에서 제공하는 사이트입니다.

## 사이트 구성

- 수행평가 제작 안내서
- 일반화학 시뮬레이션 예시 주제 목록
- 주제 신청 구글 폼
- 학생용 HTML 시작 템플릿
- 최종 작품 제출 구글 폼
- 학생 작품 갤러리(21개 작품, 주제 필터와 공용 좋아요 제공)

## 파일 구성

- `index.html`: 수행평가 안내 메인 페이지
- `gallery.html`: 주제별 학생 작품 갤러리 및 공용 좋아요 페이지
- `works/`: 학번·실명을 제거한 독립 실행형 HTML 작품
- `likes-apps-script.js`: 공용 좋아요 저장용 Google Apps Script 원본
