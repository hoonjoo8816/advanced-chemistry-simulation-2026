THREE SESSIONS

세 차시 안에
완성하는 흐름

처음부터 큰 프로그램을 만들기보다, 한 가지 변인이 결과에 미치는 영향을 분명하게 보여 주는 작은 모델부터 완성하세요.

1차시

주제 선정과 설계

탐구 질문을 정하고 조작 변인, 관찰 결과, 사용할 화학식과 가정을 설계합니다.

2차시

구현과 상호작용

AI와 시작 템플릿을 활용해 입력 도구, 계산, 그래프 또는 입자 모형을 구현합니다.

3차시

검증과 제출

기준값과 경계 조건을 시험하고 설명, 한계, 출처를 정리한 뒤 HTML 파일을 제출합니다.

QUALITY CHECK

평가에서 보는 것

세부 배점은 최종 제작 안내서를 기준으로 합니다. 아래 항목은 제작 중 스스로 점검해야 할 핵심 관점입니다.

과학적 정확성화학식, 단위, 계산과 개념 설명이 타당한가?
모델과 탐구 설계변인과 결과의 관계가 분명하고 가정이 드러나는가?
상호작용과 표현값을 조절했을 때 변화가 이해하기 쉽게 나타나는가?
검증과 한계기준값, 경계 조건, 예외와 적용 범위를 점검했는가?
설명과 출처사용한 자료와 참고 출처를 확인할 수 있는가?
완성도오류 없이 실행되고 제출 형식을 지켰는가?
AI USE GUIDE

AI는 제작을 돕지만,
검증은 제작자의 몫입니다.

생성된 코드와 설명을 그대로 믿지 말고, 교과서·신뢰할 수 있는 자료·직접 계산한 기준값으로 결과를 확인하세요. 자신이 설명할 수 있는 범위로 완성해야 합니다.

BEFORE SUBMIT

제출 전 마지막 점검

파일을 제출하기 전에 아래 네 가지를 확인하세요. 다른 기기에서도 HTML 파일이 정상적으로 열리는지 확인하면 좋습니다.

✓
입력과 결과 확인최솟값·최댓값·특수 조건에서도 오류가 없는지 시험합니다.
✓
단위와 식 확인사용한 상수, 단위 변환과 계산식을 다시 확인합니다.
✓
설명과 한계 작성모델의 가정과 실제 현상과의 차이를 화면에 적습니다.
✓
파일 이름 정리안내서에서 정한 형식으로 HTML 파일 이름을 저장합니다.
